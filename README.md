# Mlab Scripts

### What is this repo.
This repository is a collection of scripts which I use to manage my multiple
computers, homelabs, and my note taking system. It is subdivided into four main
folders, which are outlined below

### Laptop
The main scripts kept here are my laptop autoconfiguration script which I use to
bring up my system when I set up a new laptop, as well as my tmux shell I run
which contains my most used TUI applications. I also keep a copy of my ZSH
config here for my laptop.

### Homelab
I'm a bit weird and run my homelab with Kubernetes, Flux, and GitOps so this
file contains a copy of my Ansible files which I use to bring up my system.

### Zettelkasten
This is a family of Pythin scripts which I use along with my Zettelkasten note
taking system to help manage all of my notes.
